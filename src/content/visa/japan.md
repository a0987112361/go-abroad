# 台灣護照去日本要簽證嗎？

**結論**：**不需要簽證**。持中華民國護照可以免簽進入日本，最多停留 **90 天**。

## 護照效期要求

日本對台灣護照的效期要求是 **「涵蓋停留期間」即可**，沒有像很多國家要求 6 個月以上。但為了避免航空公司在登機時刁難，建議護照效期仍預留 **6 個月以上** 比較保險。

## 入境會被問什麼？

日本入境審查官常見問題：

1. **訪日目的**（觀光 / 出差 / 探親）
2. **停留天數**
3. **住宿地址**（飯店名稱、Airbnb 地址）
4. **回程機票**

建議事先把以下資料截圖或印出：
- 飯店訂房確認信
- 回程機票 e-ticket
- 行程表（如果有）

## Visit Japan Web 線上表單

從 2023 年起，日本啟用 **Visit Japan Web** 系統，可預先填寫入境卡和海關申報，現場掃 QR Code 通關，不用再寫紙本。

- 網址：vjw-lp.digital.go.jp
- 建議出發前 **6 小時前** 完成
- 仍可現場填紙本，但會排比較久

## 90 天免簽可以做什麼？

✅ **可以**：
- 觀光、購物、探親
- 短期商務洽談、參加會議
- 短期語言進修（不發學位）

❌ **不可以**：
- 任何形式的「打工」（含打工度假需另外申請打工度假簽證）
- 領薪水的工作
- 超過 90 天的停留

## 我可以連續入境刷停 90 天嗎？

技術上可以，但如果短期內多次出入境，**入境審查會懷疑你長期在日本生活**，可能被拒絕入境。

## 打工度假 / 留學 / 工作怎麼辦？

需要另外申請對應簽證：

| 用途 | 申請類型 |
|---|---|
| 打工度假（18–30 歲） | 打工度假簽證（每年配額） |
| 語言學校 6 個月+ | 留學簽證 |
| 在日本上班 | 工作簽證（需公司擔保） |

詳細申請方式請洽 **日本台灣交流協會台北事務所**。
