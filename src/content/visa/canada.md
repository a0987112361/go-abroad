# 台灣護照去加拿大要簽證嗎？

**結論**：**需要申請 eTA**（電子旅行授權），通過後可**免簽停留最多 180 天（半年）**。

## eTA 申請

1. **官網**：[canada.ca/eta](https://www.canada.ca/eta)（**認準 .ca，避免被收高額代辦費**）
2. 線上填表
3. **費用 CAD 7**（約 NT$170，比 ESTA 便宜很多）
4. 多數案例幾分鐘核准，少數人工審核 72 小時內
5. 有效期 **5 年**或護照到期前，期間內多次入境

⚠️ **常見坑**：搜尋「Canada eTA」會跳出很多代辦網站收 USD 50+，務必認準 `.canada.ca`。

## eTA 不適用情境

以下需另外申請正式簽證（VR / Study / Work permit）：
- 從加美陸地邊界開車入境（eTA 是空運才需）
- 念書 6 個月以上
- 工作簽證
- 永久居留申請者

## 護照效期要求

**護照剩餘效期需 6 個月以上**，且必須是電子晶片護照。

## 入境須備文件

1. **eTA 核准郵件**（系統會自動連結護照，建議截圖備用）
2. **護照**
3. **回程或前往第三國機票**
4. **住宿訂房 / 親友地址**
5. **財力證明**（建議至少 CAD 1,000 / 週）

## 180 天可以做什麼？

✅ 觀光、探親、商務考察、短期語言學校（< 6 個月）

❌ 受聘工作、念學位、移民

## 入境海關（CBSA）審查

- 帶充足現金 / 信用卡
- 行程要清楚（哪天去哪、住哪）
- 誠實申報攜帶物品（食物、藥品、現金 CAD 10,000+）

## 加美陸地邊境

從美國開車進加拿大，**不需要 eTA**，但仍需護照 + 回答邊境問題。從加拿大進美國則需要美國 ESTA / 簽證。

## 入境注意事項

- **大麻**：在加拿大全國合法，但**禁止攜帶過境**（出境也禁帶）
- **食物**：肉類、奶製品、蔬果全禁
- **現金 CAD 10,000+**：要申報

## 想久留 / 念書 / 工作？

| 簽證類型 | 用途 |
|---|---|
| 學生簽（Study Permit） | 念書 |
| 工作簽（Work Permit） | 受聘 |
| 打工度假（IEC） | 18–35 歲，每年抽籤 |
| 永久居留 PR | 移民 |
