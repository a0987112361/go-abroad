# 台灣護照去澳洲要簽證嗎？

**結論**：**需要簽證**。台灣護照可線上申請 **ETA（Electronic Travel Authority, 651）**，核准後可停留 **90 天**。

⚠️ **注意**：澳洲對歐盟、英國等發達國家公民提供「**eVisitor (subclass 651)**」**免費**簽證，但**台灣護照不在 eVisitor 清單**，必須申請 **ETA (subclass 601)**，費用 **AUD 20**。

## ETA 申請

1. **官網**：[immi.homeaffairs.gov.au](https://immi.homeaffairs.gov.au/visas/getting-a-visa/visa-listing/electronic-travel-authority-651)
2. **手機 App「Australian ETA」**（推薦）或透過旅行社代辦
3. **費用 AUD 20**（信用卡）
4. 多數案例幾分鐘核准
5. 有效期 **12 個月**或護照到期前，期間內多次入境，**每次最多 90 天**

⚠️ App 申請有時會在「拍護照晶片」步驟卡住，可改用旅行社代辦。

## 護照效期要求

**護照剩餘效期需 6 個月以上**，且必須是電子晶片護照。

## 入境須備文件

1. **ETA 核准**（系統會自動連結護照）
2. **護照**
3. **回程或前往第三國機票**
4. **住宿訂房 / 親友地址**
5. **財力證明**（建議 AUD 1,000 / 週）

## 90 天可以做什麼？

✅ **可以**：
- 觀光、探親、商務洽談、會議
- 短期語言課程（< 90 天）

❌ **不可以**：
- 受聘工作（打工度假需另外申請 462 簽）
- 念學位
- 海上工作 / 漁工

## 入境海關（生物安全極嚴）

澳洲生物安全是**全球最嚴格之一**：

| 物品 | 規定 |
|---|---|
| 食物（含泡麵調理包、肉乾、零食） | **必申報**，多數會沒收 |
| 種子、堅果、新鮮水果蔬菜 | 全禁 |
| 木製品（藝品、樂器） | 申報，可能要熏蒸 |
| 中藥材 | 嚴格管制 |
| 非處方藥（成藥） | 帶英文成分標示 |

⚠️ **不確定就申報**，未申報罰 AUD 6,260+，常被遣返並 3 年禁入。

## 想久留 / 念書 / 工作？

| 簽證類型 | 用途 |
|---|---|
| 學生簽（500） | 念書 |
| 打工度假（417 / 462） | 18–30 歲（台灣是 462） |
| 工作簽（482） | 受聘 |
| 永久居留 | 技術移民、家庭團聚 |

## 入境注意事項

- **菸草**：每人限 25 支香菸或 25 克菸絲，超過要報關
- **酒類**：限 2.25 公升
- **現金 AUD 10,000+**：要申報
