# 台灣護照去紐西蘭要簽證嗎？

**結論**：**需要 NZeTA**（紐西蘭電子旅行授權）**+ IVL 觀光稅**。核准後免簽 **90 天**。

## NZeTA + IVL 申請

兩者必須**一起申請**：

| 項目 | 費用 | 說明 |
|---|---|---|
| **NZeTA** | NZD 17（App）/ 23（網頁） | 入境授權 |
| **IVL 國際觀光稅** | NZD 100 | 一同收取，不可避免 |

合計約 **NZD 117–123**（NT$2,400–2,500）。

## 申請步驟

1. **官網**：[immigration.govt.nz](https://www.immigration.govt.nz/new-zealand-visas/apply-for-a-visa/about-visa/nzeta)
2. **「NZeTA」手機 App**（最便宜）或網頁
3. 信用卡付費
4. 多數 **72 小時內** 核准
5. 有效期 **2 年**或護照到期前

⚠️ **常見坑**：搜尋會跳出代辦網站收 USD 50+，認準 `.govt.nz`。

## 護照效期要求

**護照剩餘效期需 3 個月以上**（離開後算起）。

## 入境須備文件

1. **NZeTA 核准 + IVL 收據**（系統自動連結護照）
2. **護照**
3. **回程或前往第三國機票**
4. **住宿訂房**
5. **財力證明**（NZD 1,000 / 月以上）

## 90 天可以做什麼？

✅ 觀光、探親、商務考察、會議

❌ 受聘工作、念學位

## 入境海關（生物安全極嚴）

紐西蘭跟澳洲一樣**生物安全極嚴**：

| 物品 | 規定 |
|---|---|
| 食物（含泡麵、肉乾、餅乾） | 必申報 |
| 種子、新鮮蔬果 | 全禁 |
| 蜂蜜 | 全禁 |
| 木製品 | 申報 |
| 登山健行裝備（鞋、帳篷） | 申報並消毒 |

⚠️ 未申報罰款 NZD 400 即決。

## 想久留 / 念書 / 工作？

| 簽證 | 用途 |
|---|---|
| Student Visa | 念書 |
| Working Holiday | 18–30 歲（台灣有配額） |
| Essential Skills | 受聘 |

## 入境注意事項

- **電子菸**：合法但限制嚴格
- **大麻**：違法
- **現金 NZD 10,000+**：要申報
