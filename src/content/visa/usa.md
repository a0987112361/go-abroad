# 台灣護照去美國要簽證嗎？

**結論**：**需要 ESTA**（電子旅行授權），但**不需要傳統簽證**。台灣是美國免簽計畫（VWP, Visa Waiver Program）會員國，台灣護照可申請 ESTA 後免簽入境美國。

## ESTA 申請

1. **官網**：[esta.cbp.dhs.gov](https://esta.cbp.dhs.gov/)（**認準 .gov，避開代辦詐騙網站**）
2. 線上填表（個人資料、護照、行程、健康、犯罪紀錄等）
3. **費用 US$21**（信用卡）
4. 約 **72 小時內** 收到核准郵件，**有效期 2 年**或護照到期前
5. 期間內可多次入境，每次最多 90 天

⚠️ **建議出發前 7 天前申請**，少數情況需人工審核較久。

## ESTA 申請被拒？

ESTA 不是 100% 通過。常見被拒原因：
- 曾被美國拒絕入境或遣返
- 曾在美國逾期停留
- 曾申請美簽被拒
- 曾去過某些國家（伊朗、伊拉克、利比亞、索馬利亞、蘇丹、敘利亞、葉門、北韓、古巴等）

被拒後需改申請傳統 **B1/B2 簽證**（面試 + 文件）。

## 護照效期要求

**護照需為晶片電子護照（e-passport）**，且效期至少 6 個月以上。

## 入境須備文件

1. **ESTA 核准郵件**（截圖即可，海關會在系統查到）
2. **護照**
3. **回程或前往第三國機票**（必查）
4. **住宿訂房 / 親友地址**
5. **財力證明**（信用卡或現金）

## 90 天可以做什麼？

✅ **可以**：
- 觀光、探親、商務洽談、會議
- 短期商務考察
- 短期語言學校（< 18 小時/週）

❌ **不可以**：
- 任何形式的受聘工作或領薪
- 念學位
- 報導記者活動（需 I 簽證）
- 婚姻簽證類用途（需 K-1）

## 入境海關（CBP）審查

- **指紋採集 + 拍照**
- **問訪美目的、停留天數、住宿、回程日期**
- 要態度誠實但簡潔，不要編故事
- 帶**充足現金 / 信用卡證明財力**

## 想久留 / 念書 / 工作？

| 簽證類型 | 用途 |
|---|---|
| F-1 | 學生 |
| H-1B | 受聘工作 |
| L-1 | 公司內部調動 |
| O-1 | 特殊專業人才 |
| EB-5 | 投資移民 |

## 入境注意事項

- **電子菸**：聯邦合法但部分州限制（如紐約）
- **大麻**：聯邦違法但部分州合法（CA、CO、WA、IL、NY 等），跨州攜帶仍違法
- **食物**：肉類、蔬果幾乎全禁帶，違者重罰
- **現金 USD 10,000+**：要申報
