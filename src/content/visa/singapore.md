# 台灣護照去新加坡要簽證嗎？

**結論**：**不需要簽證**，可免簽停留 **30 天**。**但必須線上完成 SG Arrival Card**。

## SG Arrival Card（必填）

新加坡自 2022 年起所有入境者都必須線上填寫 SG Arrival Card，包括：
- 個人資料 + 航班
- 健康聲明
- 海關申報

申請：
- 網址：[eservices.ica.gov.sg/sgarrivalcard](https://eservices.ica.gov.sg/sgarrivalcard/)
- **抵達前 3 天內** 填寫
- **免費**
- 完成後保留確認郵件 / 截圖

⚠️ **沒填的話**：可在新加坡機場現場補填，但會嚴重延誤、影響行程。

## 護照效期要求

**護照剩餘效期需 6 個月以上**。

## 入境須備文件

1. **SG Arrival Card 確認**（手機截圖）
2. **護照**
3. **回程或前往第三國機票**（**必查**）
4. **住宿訂房**
5. **充足財力證明**（信用卡或 SGD 現金）

## 入境海關 — 嚴格度全球前列

新加坡海關以**世界最嚴**聞名，務必注意：

| 嚴格管控物品 | 處罰 |
|---|---|
| **電子菸**（IQOS、JUUL 等） | 攜帶最高罰 SGD 2,000，使用最高罰 SGD 10,000 |
| **口香糖** | 一般口香糖禁止攜帶 |
| **毒品** | 死刑（包括大麻、印尼帶來的鴉片） |
| **打火機液（瓶裝）** | 禁帶 |
| **未申報現金 SGD 20,000+** | 沒收 + 罰款 |

## 30 天可以做什麼？

✅ 觀光、購物、轉機、短期會議

❌ 工作、長期居留、街頭表演（需牌照）

## 想久留？簽證選項

| 簽證類型 | 用途 |
|---|---|
| 工作准證（EP / S Pass） | 受僱 |
| 學生准證 | 留學 |
| LTVP | 配偶/家屬 |
| 旅遊延期 | 抵達後申請 |

## 樟宜機場過境免簽（VFTF）

如果你是搭新航/酷航等過境（不入境），可使用 **96 小時過境免簽**，但需符合：
- 機票是聯程
- 不離開中轉區，或入境僅短暫遊覽
